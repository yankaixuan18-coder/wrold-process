# ⚽ 2026 美加墨世界杯比分预测

一个纯静态网页应用，可以预测 2026 年美国/加拿大/墨西哥世界杯任意对阵的比分、小组出线形势以及各队夺冠概率。无需安装任何依赖，浏览器打开即用。

## 功能

| 功能 | 说明 |
| --- | --- |
| **对阵预测** | 任选两队，给出最可能比分、胜平负概率、最可能的 6 个比分、比分概率热力图；淘汰赛模式额外计算含加时与点球的晋级概率 |
| **小组赛模拟** | 选择 A–L 任意小组，模拟 5000 次给出每队的平均积分与前二出线率，并列出 6 场比赛的最可能比分 |
| **全程夺冠模拟** | 蒙特卡洛模拟整届世界杯（104 场）数千次，统计 48 队的小组出线率、16 强 / 8 强 / 4 强 / 决赛 / 夺冠概率 |

## 使用方法

**方式一：本地直接打开**

下载或克隆本仓库后，双击 `index.html` 即可（无需服务器）。

**方式二：本地起一个简易服务器**

```bash
cd wrold-process
python3 -m http.server 8000
# 浏览器访问 http://localhost:8000
```

**方式三：GitHub Pages 在线托管**

仓库 Settings → Pages → 选择分支与根目录，保存后即可获得在线网址。

## 预测模型

1. **Elo 实力评分**：每队一个评分（`js/data.js` 中可手动调整），参考 eloratings.net 与 FIFA 排名估算；东道主美/加/墨默认 +75 主场加成。
2. **预期进球**：由两队 Elo 差换算双方预期进球数（实力相当时各约 1.38 球）。
3. **泊松分布**：双方进球数各自服从泊松分布，相乘得到每个具体比分（0:0 ~ 8:8）的概率。
4. **淘汰赛**：90 分钟战平后按 1/3 强度模拟加时赛，再平则进行按实力差微调的点球大战。
5. **全程模拟**：小组赛分组与 32 强对阵模板（M73–M88）均采用官方真实数据，最佳小组第三按官方限定槽位回溯匹配；16 强之后按相邻对阵推进（近似官方走位）。

## 数据说明

- 分组为 2025 年 12 月 5 日华盛顿抽签 + 2026 年 3 月附加赛后的**最终 48 强**：欧洲附加赛晋级的是波黑、瑞典、土耳其、捷克（意大利、丹麦被淘汰），洲际附加赛晋级的是刚果（金）与伊拉克。
- 球队评分截至 2026 年 6 月开赛前，可在 `js/data.js` 中随时修改。
