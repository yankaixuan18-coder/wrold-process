# ⚽ 2026 美加墨世界杯比分预测

一个纯静态网页应用，用 **3 个独立数据源 × 3 个测算模型 + 加权集成** 预测 2026 年美国/加拿大/墨西哥世界杯任意对阵的比分、小组出线形势以及各队夺冠概率。无需安装任何依赖，浏览器打开即用。

## 功能

| 功能 | 说明 |
| --- | --- |
| **对阵预测** | 任选两队，四个模型（Elo / FIFA 排名 / 市场赔率 / 集成）并排对比各自的最可能比分与胜平负概率；集成权重可实时调节；含比分热力图，淘汰赛模式额外计算加时与点球的晋级概率 |
| **小组赛模拟** | 选择 A–L 任意小组与任意模型，模拟 5000 次给出每队平均积分与前二出线率 |
| **全程夺冠模拟** | 蒙特卡洛模拟整届世界杯（104 场）数千次，可分别用四个模型对比 48 队的出线 / 16 强 / 8 强 / 4 强 / 决赛 / 夺冠概率 |
| **淘汰赛预测** | 按各组排名生成 32 强真实签表，逐轮预测每场（加时/点球晋级概率，进球收缩），可录入真实淘汰赛结果自动向下一轮传导，并给出各队夺冠/晋级概率 |
| **实时积分榜** | 用已录入赛果按 FIFA 规则算各组当前真实排名（积分→净胜球→进球→相互战绩），并叠加模型对剩余比赛的前二出线概率与每队余赛 |
| **投注推荐** | 选择某一比赛日，基于当前赔率给出每场的「稳 / 冲」单场推荐（胜平负 / 双重机会 / 大小球 / 双方进球 / 正确比分）与当日「稳串 / 冲串」串票，按凯利公式给出建议仓位；可录入**真实赔率**让 EV 基于实盘计算，可一键「记台账」 |
| **AI 分析** | 用大模型（DeepSeek / Claude / GPT，填自己的 Key）结合最新情报判断每场的求胜动机，并把**假球 / 默契球 / dead rubber** 风险与可能比分加入模型；开启「应用」后作用于所有预测、模拟与投注估值。也支持手动录入（无需 Key） |
| **投注台账** | 记录真实下注与输赢，统计累计盈亏、ROI、命中率，让工具能自我验证 |
| **回测校准** | 对已结束比赛做时序回放（无未来信息泄漏），算 Brier 分数、对数损失、胜平负/比分命中率、进球 MAE，并与市场、均匀基准对照，附校准曲线 |
| **实际赛果** | 录入小组赛真实比分（保存在浏览器本地）：已赛场次直接计入所有模拟，并按 Elo 公式对各队实力做动态修正，越冷门的赛果修正越大 |
| **数据源** | 48 队三大数据源（Elo、FIFA 积分、夺冠赔率）+ 赛果动态修正一览与综合实力排名 |

## 三个模型 + 集成

1. **Elo 模型**：eloratings.net 风格实力分直接相减，东道主美/加/墨 +75 主场加成。
2. **FIFA 排名模型**：FIFA 官方积分差（乘换算系数对齐 Elo 尺度），侧重近年正式比赛战绩。
3. **市场赔率模型**：博彩公司夺冠赔率 → 隐含概率 → 对数尺度反推实力。市场已计价阵容、伤病、主场等因素，故不再叠加主场加成。
4. **集成模型**（默认）：对三个模型的实力分差加权平均，权重可在页面上实时调节。多源集成可抵消单一数据源的偏差，是提升预测稳健性最有效的手段。

比分生成统一走：实力差 → 双方预期进球（势均力敌时各约 1.38 球）→ 泊松分布 → 每个具体比分（0:0 ~ 8:8）的概率。淘汰赛战平后按 1/3 强度模拟加时，再平按实力差微调的点球。

两个精度增强：

- **Dixon-Coles 低比分修正**（可开关）：独立泊松会系统性低估 0:0 / 1:1、高估 1:0 / 0:1，按经典 Dixon-Coles (1997) τ 系数（ρ = −0.13）校正，蒙特卡洛抽样也从修正后的比分分布取样。
- **赛果动态更新**：在「实际赛果」页录入真实比分后，按 Elo 更新公式（K=50，净胜球放大系数，预期值来自集成模型）对球队实力做贝叶斯式修正，修正叠加到所有模型；已赛场次在模拟中不再随机而是直接采用真实比分。赛果存于 localStorage，刷新不丢失。
- **攻防修正层（可开关，`js/form.js`）**：小组赛后，用每队「实际进/失球」相对「模型按实力预期进/失球」的偏差，经验贝叶斯收缩（伪计数 K=6）得到进攻/防守系数，λ 乘以「己方进攻 × 对手防守」——与 Elo 实力修正正交（实力管强弱、攻防管进球多寡与风格）。收缩很强、样本少时几乎为 1，避免过拟合；庄家盘口与回测不受其影响以保持基准干净。「对阵预测」页勾选「攻防修正」即全局启用。

## 投注推荐（价值法）

「投注推荐」页基于**期望价值（EV）**给出建议：

1. **庄家盘口**：用市场赔率模型的概率，按抽水（胜平负盘 ~7%、正确比分盘 ~22%）折算成十进制赔率，并保持赛前市场不变。
2. **我方估计**：用所选模型（默认 **Elo+FIFA，剔除市场**，以便与盘口形成分歧）算出真实概率，并吸收已录入赛果的动态修正。
3. **价值**：`EV = 我方概率 × 庄家赔率 − 1`，EV > 0 即理论上有利可图（价值来自我方与市场的分歧，以及球队在已赛场次中的超/欠预期表现）。
4. **稳 / 冲**：
   - **稳** = 高命中率盘（双重机会、大小球等，低赔稳健），同等条件优先有正价值；
   - **冲** = 正价值的高赔盘（冷门、正确比分，高风险高回报）。
5. **仓位**：按凯利公式给出建议投注比例（稳取 ¼ 凯利、上限 5%；冲取 ½ 凯利、上限 10%；无正期望则建议跳过）。
6. **串票（串）**：当日各场各取一条腿相乘——稳串求高命中、冲串求高赔率。串票按各腿独立近似相乘，**会高估真实命中率，越串越难中**。

> 完整小组赛赛程（72 场，含日期、对阵与已赛比分）在 `js/schedule.js`，来源为 FIFA / ESPN / Yahoo 等公开赛程并逐场核对。

## AI 比赛动机与假球分析

纯泊松模型有个根本盲区：它假设每队都全力争胜，**抓不到「非竞争性比赛」**——已出线/出局的 dead rubber、末轮双方都满意某比分而默契踢平、主力轮换、摆烂。「AI 分析」页用大模型补上这块：

1. **配置**：在页面填入你自己的 API Key，服务商可选 **DeepSeek / GPT / Claude 官方直连**，或路由商 **OpenRouter / Requesty**（一个 Key 用多模型）。模型可自定义，默认值分别为 `deepseek-chat` / `gpt-4o` / `claude-opus-4-8` / `deepseek/deepseek-chat`（OpenRouter）/ `deepseek/deepseek-v4-pro`（Requesty）。注意：**服务商与 Key 必须匹配**——OpenRouter 用 `sk-or-` 开头、Requesty 用 `rqsty-` 开头、DeepSeek 官方用 `sk-` 开头，填错会报 “Missing Authentication header” 之类的鉴权错误。
2. **分析**：选比赛日、可选粘贴最新情报（伤病/轮换/出线形势/新闻），AI 对当日未赛场次逐场输出结构化判断：双方预期进球的缩放系数、求胜动机、**假球/默契风险**及其可能比分、关键因素。
   - **检索来源（可选，4 选 1）**：纯静态网页受 CORS 限制无法直接抓取谷歌/必应，但可用以下来源拿最新信息——
     - **维基百科（自制·免 Key·推荐）**：我们自己写的检索（`js/retriever.js`），直连维基开放 API（`w/api.php?origin=*` 搜索 + `api/rest_v1/page/summary` 取摘要），**不走任何检索服务商、不用 Key**。检索双方国家队 + 该组世界杯词条，适合球队资料与赛事进程；同日伤病/首发覆盖有限。
     - **自定义端点（自建）**：填你自托管的 [SearXNG](https://github.com/searxng/searxng) 等检索 URL（用 `{q}` 占位查询词，返回 JSON），完全自主可控，不依赖商业服务商。
     - **OpenRouter 自带**：服务商选 OpenRouter 时，用其 web 插件（`plugins:[{id:'web'}]`），一个 Key 同时拿到 DeepSeek + 联网，来源取自返回 `annotations`。
     - **Tavily**：填 [Tavily](https://tavily.com) Key 作前置检索（topic=news、近 21 天）。
     结果卡片都会列出引用来源链接。
3. **接入模型**：开启「在所有预测/模拟/投注中应用 AI 调整」后，
   - 预期进球按动机系数缩放（如摆烂队 ×0.5）；
   - 比分分布按 `最终 = (1−风险)×正常分布 + 风险×情景分布` 混合（如 60% 默契平局风险会显著抬高 1:1 概率）；
   - 这套调整随之作用于对阵预测、小组/全程模拟、投注估值。
4. **手动录入**：无需 Key 也能直接录入动机系数与假球情景，便于离线试用或注入你自己的判断。

### 诚实的限制

- **纯静态网页无后端**：API Key 只存在你本地浏览器（localStorage），调用时**从浏览器直接请求**各家接口——需对方允许跨域（Anthropic 已带浏览器直连头 `anthropic-dangerous-direct-browser-access`；DeepSeek/OpenAI 通常允许）。Key 不会上传到任何第三方。
- **「最新信息」**：基础聊天模型不会自动联网；不开 Tavily 时最新情报靠你粘贴 + 模型自身知识，开启 Tavily 后则由它实时检索新闻补充。Tavily 与 LLM 的 Key 都只存本地浏览器。
- **假球风险是统计推断，不是事实指控**：模型只依据公开赛况（出线形势、dead rubber、轮换）给出概率，提示词明确要求不做无证据指控。预测仅供娱乐参考。

## 淘汰赛预测

小组赛结束后进入「淘汰赛预测」页：

1. **真实签表**：按各组当前排名取 1、2 名 + 8 个最佳第三，依官方 M73–M88 槽位 + **FIFA 官方 Annexe C「最佳第三分配表」**（495 种组合的固定对照表，`js/allocation.js`）生成 32 强对阵——例如德国（E 组头名）对阵的是 D 组第三（巴拉圭），与官方一致。小组赛未踢完时为「按当前积分的临时投影」，录满 72 场后即为真实对阵。
2. **逐轮预测**：每场给出最可能比分与**含加时/点球的晋级概率**。淘汰赛模型做了针对性进化——预期进球整体收缩（`KO_GOAL_SCALE`，淘汰赛场面更紧、更易低比分/拖加时），战平按 1/3 强度加时、再平点球（按实力差微调）。
3. **结果录入与传导**：录入任意一场真实淘汰赛比分与晋级方后，胜者自动进入下一轮对阵，并被全局蒙特卡洛采纳（`decideKnockout` 优先使用已录入结果）——后续所有夺冠/晋级概率随之更新。
4. **夺冠/晋级概率**：蒙特卡洛 5000 次（已结合所有已录入的小组与淘汰赛结果）给出各队进 16 强 / 8 强 / 4 强 / 决赛 / 夺冠概率。

## 回测与可信度

「回测校准」页用**时序回放**检验模型：按日期顺序逐场预测，预测每场时只用此前的赛果做动态修正（杜绝未来信息泄漏），再与真实结果比对：

- **Brier 分数 / 对数损失**（越低越好）：模型在这两项上低于「市场模型」即说明赛前预测比盘口更准；「均匀基准」（各 1/3）作为下限参照。
- **校准曲线**：把预测概率分箱，对比「预测均值」与「实际命中频率」，两者越接近说明概率越可信（不高估也不低估）。

> ⚠️ 样本越少结论越不稳——小组赛初期只有几场，指标会很跳；随着比赛进行参考价值才上升。

### 尚未加入：球队攻防分项评分

更进一步的精度升级是给每队独立的「攻击力/防守力」（完整双变量泊松），以区分"对攻型"和"防守型"球队。但要做得有诚信需要真实的逐队进失球数据来拟合；仅凭世预赛数据（对手强弱差异极大）或只有 3 场小组赛会变成"假精度"，因此本版本暂未加入，留作后续在样本充足后引入。

## 数据来源（真实数值 + 来源标注）

每个数值在「数据源」页都带来源标记（✓ 实测/官方，≈ 单源近似，~ 推算/按排名），并列出来源链接与日期。

- **分组与赛制（真实）**：2025-12-05 华盛顿抽签 + 2026 年 3 月附加赛后的最终 48 强（波黑、瑞典、土耳其、捷克与刚果（金）、伊拉克附加赛晋级；意大利、丹麦出局）；32 强对阵采用官方 M73–M88 模板，最佳小组第三按官方限定槽位回溯匹配。
- **FIFA 积分（2026-04-01）**：48 队中 **41 队为官方公布积分**（如法国 1877.32、西班牙 1876.40、阿根廷 1874.81…），来源 [FIFA 官方排名](https://inside.fifa.com/fifa-world-ranking/men) / [ESPN Top-50](https://www.espn.com/soccer/story/_/id/46664763/fifa-mens-top-50-world-rankings) / [football-ranking.com](https://football-ranking.com/fifa_rankings)；其余 7 队（伊朗、卡塔尔、伊拉克、南非、沙特、约旦、波黑）仅知排名，按相邻名次插值（标 `~`）。
- **Elo 评分**：48 队中 **18 队为实测**（2026-01-19 快照，来源 [eloratings.net](https://www.eloratings.net/) / [Wikipedia: World Football Elo Ratings](https://en.wikipedia.org/wiki/World_Football_Elo_Ratings) / [footballratings.org](https://www.footballratings.org/)）；其余 30 队为**可复现推算**：用各组平均 Elo（footrankings 公布，覆盖全 48 队）乘 4 减去组内实测值后，按各队 FIFA 积分比例分配——这样既还原了各组平均，又遵循 FIFA 排序，避免了凭空估值（标 `~`）。
- **夺冠赔率（2026-06 开赛前）**：BetMGM / FanDuel 行情。西班牙 +450、法国 +500、英格兰 +700、巴西 +800、葡萄牙/阿根廷 +900、德国 +1400、荷兰 +2000、挪威 +3500、哥伦比亚 +4000、乌拉圭 +6500 为报道证实，其余为市场惯例估算。来源 [FOX Sports](https://www.foxsports.com/stories/soccer/world-cup-2026-champion-odds) / [ESPN](https://www.espn.com/soccer/story/_/id/49025269/spain-france-lead-world-cup-odds-usa-bettors-back-home-team)。
- 全部数值与来源都在 `js/data.js`（含 `srcElo` / `srcFifa` 标记与 `RATINGS_META`），可手动修改，刷新页面即生效。

> 说明：Elo 的权威源 eloratings.net 对自动抓取返回 403，无法一次性取全 48 队当日值，因此采用「实测优先 + 透明推算补全」的方式，并逐队标注来源等级——这比给全部 48 队都填估算值更诚实。若你能提供完整当日 Elo 快照，替换 `js/data.js` 中的 `elo` 字段并把 `srcElo` 改为 `'src'` 即可。

## 使用方法

**方式一：本地直接打开** —— 下载或克隆本仓库后，双击 `index.html` 即可（无需服务器）。

**方式二：本地简易服务器**

```bash
cd wrold-process
python3 -m http.server 8000
# 浏览器访问 http://localhost:8000
```

**方式三：GitHub Pages 在线托管** —— 仓库 Settings → Pages → 选择分支与根目录，保存后即可获得在线网址。
