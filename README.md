# ⚽ 2026 美加墨世界杯比分预测

一个纯静态网页应用，用 **3 个独立数据源 × 3 个测算模型 + 加权集成** 预测 2026 年美国/加拿大/墨西哥世界杯任意对阵的比分、小组出线形势以及各队夺冠概率。无需安装任何依赖，浏览器打开即用。

## 功能

| 功能 | 说明 |
| --- | --- |
| **对阵预测** | 任选两队，四个模型（Elo / FIFA 排名 / 市场赔率 / 集成）并排对比各自的最可能比分与胜平负概率；集成权重可实时调节；含比分热力图，淘汰赛模式额外计算加时与点球的晋级概率 |
| **小组赛模拟** | 选择 A–L 任意小组与任意模型，模拟 5000 次给出每队平均积分与前二出线率 |
| **全程夺冠模拟** | 蒙特卡洛模拟整届世界杯（104 场）数千次，可分别用四个模型对比 48 队的出线 / 16 强 / 8 强 / 4 强 / 决赛 / 夺冠概率 |
| **实际赛果** | 录入小组赛真实比分（保存在浏览器本地）：已赛场次直接计入所有模拟，并按 Elo 公式对各队实力做动态修正，越冷门的赛果修正越大 |
| **数据源** | 48 队三大数据源（Elo、FIFA 积分、夺冠赔率）+ 赛果动态修正一览与综合实力排名 |

## 三个模型 + 集成

1. **Elo 模型**：eloratings.net 风格实力分直接相减，东道主美/加/墨 +75 主场加成。
2. **FIFA 排名模型**：FIFA 官方积分差（乘换算系数对齐 Elo 尺度），侧重近年正式比赛战绩。
3. **市场赔率模型**：博彩公司夺冠赔率 → 隐含概率 → 对数尺度反推实力。市场已计价阵容、伤病、主场等因素，故不再叠加主场加成。
4. **集成模型**（默认）：对三个模型的实力分差加权平均，权重可在页面上实时调节。多源集成可抵消单一数据源的偏差，是提升预测稳健性最有效的手段。

比分生成统一走：实力差 → 双方预期进球（势均力敌时各约 1.38 球）→ 泊松分布 → 每个具体比分（0:0 ~ 8:8）的概率。淘汰赛战平后按 1/3 强度模拟加时，再平按实力差微调的点球。

两个精度增强：

- **Dixon-Coles 低比分修正**（可开关）：独立泊松会系统性低估 0:0 / 1:1、高估 1:0 / 0:1，按经典 Dixon-Coles (1997) τ 系数（ρ = −0.13）校正，蒙特卡洛抽样也从修正后的比分分布取样。
- **赛果动态更新**：在「实际赛果」页录入真实比分后，按 Elo 更新公式（K=50，净胜球放大系数，预期值来自集成模型）对球队实力做贝叶斯式修正，修正叠加到所有模型；已赛场次在模拟中不再随机而是直接采用真实比分。赛果存于 localStorage，刷新不丢失。

## 数据来源

- **分组与赛制（真实）**：2025-12-05 华盛顿抽签 + 2026 年 3 月附加赛后的最终 48 强（波黑、瑞典、土耳其、捷克与刚果（金）、伊拉克附加赛晋级；意大利、丹麦出局）；32 强对阵采用官方 M73–M88 模板，最佳小组第三按官方限定槽位回溯匹配。
- **FIFA 积分**：2026 年 4–6 月排名。头部球队（法国/西班牙 1876.4/阿根廷/英格兰/葡萄牙的位次）为媒体报道证实，其余按最近公开排名估算。
- **夺冠赔率**：2026 年 6 月开赛前 BetMGM / FanDuel 行情。西班牙 +450、法国 +500、英格兰 +700、巴西 +800、葡萄牙/阿根廷 +900、德国 +1400、荷兰 +2000、挪威 +3500、哥伦比亚 +4000、乌拉圭 +6500 为报道证实，其余为市场惯例估算。
- **Elo 分**：按开赛前水平估算。
- 全部数值都在 `js/data.js`，可手动修改，刷新页面即生效。

## 使用方法

**方式一：本地直接打开** —— 下载或克隆本仓库后，双击 `index.html` 即可（无需服务器）。

**方式二：本地简易服务器**

```bash
cd wrold-process
python3 -m http.server 8000
# 浏览器访问 http://localhost:8000
```

**方式三：GitHub Pages 在线托管** —— 仓库 Settings → Pages → 选择分支与根目录，保存后即可获得在线网址。

## 文件结构

```
index.html      页面入口
css/style.css   样式
js/data.js      48 强数据（Elo / FIFA 积分 / 夺冠赔率 / 分组 / 对阵模板）
js/results.js   实际赛果存储与 Elo 动态修正
js/model.js     多模型预测引擎（3 模型 + 集成 → 泊松 + Dixon-Coles → 蒙特卡洛）
js/app.js       页面交互
```
